# Feestdagen API 🇳🇱

Dit project laat de eerstvolgende feestdag in Nederland zien met behulp van een API.

## 🎯 Wat doet deze applicatie?
De applicatie haalt gegevens op van een externe API en toont automatisch de eerstvolgende feestdag in Nederland op het scherm.

## ⚙️ Hoe werkt het?
- Er wordt een GET request gedaan naar een API
- De API geeft een lijst met feestdagen
- De code zoekt de eerstvolgende datum na vandaag
- Deze feestdag wordt weergegeven op de pagina

## 🛠️ Gebruikte technieken
- HTML (structuur van de pagina)
- JavaScript (functionaliteit)
- Fetch API (data ophalen van internet)

## 🌐 API
Voor dit project is gebruik gemaakt van de volgende API:  
https://date.nager.at

## ✅ Functionaliteiten
- Data ophalen van een externe API
- Eerstvolgende feestdag berekenen
- Weergeven van datum en naam van de feestdag
